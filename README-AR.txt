أرفقنا css/style.css وjs/app.js مرتبين للمراجعة والتطوير. عند تعديلهما انسخ التعديل إلى وسم style أو script داخل HTML، لأن الصفحات تستخدم النسخ المدمجة.
كود الصورة المدمجة طويل بطبيعته؛ بقية الأكواد موزعة على أسطر.
