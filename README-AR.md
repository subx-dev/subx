# SUBX — Robot Scroll Experience

هذه النسخة الجديدة لموقع SUBX مبرمجة بـ HTML + CSS + JavaScript + WebGL خام، من دون أي مكتبات أو ملفات يتم جلبها من الإنترنت.

## كيف تشغّل الموقع؟

1. فكّ الملف المضغوط؛ لا ترفع الملف ZIP نفسه إلى GitHub كموقع.
2. افتح `index.html` مباشرة من المتصفح على الكمبيوتر أو الجوال. يعمل بدون تثبيت تطبيق، وبلا اتصال إنترنت.
3. للرفع إلى GitHub Pages: ارفع **محتويات المجلد** إلى جذر المستودع، بما فيها `css` و`js` و`assets` وملف `amwali.html`، مع الحفاظ على نفس الأسماء والمجلدات.
4. من Settings → Pages اختر Deploy from a branch ثم `main / root` واحفظ.

## ما الجديد؟

- روبوت ثلاثي الأبعاد مرسوم برمجيًا، وليس فيديو ثابتًا.
- اقتراب الكاميرا من الروبوت مع النزول، ثم انفصال الأجزاء وظهور الدوائر الداخلية.
- الانتقال إلى نفق رقمي، ثم معاينة شاشة تطبيق أموالي، ثم الدخول إلى محرّر أكواد تفاعلي.
- علامات تقدّم الرحلة، قوائم الجوال، روابط الأقسام، صفحة المشروع، واجهة التواصل، والنسخ من محرر الأكواد.
- الصفحة تعمل بلا خدمات سحابية أو مكتبات CDN. الأكواد داخل محرر الموقع **نماذج توضيحية** وليست المصدر الفعلي لتطبيق أموالي.

## ملاحظات

- لكي يعمل رسم الروبوت ثلاثي الأبعاد، يحتاج المتصفح إلى دعم WebGL. إذا كان غير متوفر تُعرض صورة روبوت احتياطية.
- على الأجهزة الضعيفة قد ينخفض معدل الإطارات. راعينا حدود دقة الرسم للشاشات الصغيرة.
- نموذج التواصل يجهّز الرسالة في تطبيق البريد؛ لا يرسل بيانات إلى خادم ولا يوهم بإرسال ناجح.
- `update/app-debug.apk` ليس مرفقًا، وأي زر تحميل في صفحة التطبيق سيعمل فقط بعد وضع ملف APK الصحيح هناك.
- ارفع **كل الملفات والمجلدات** لتعمل التنقلات والتنسيقات. لا ترفع `index.html` وحده.
