# SUBX — النسخة النهائية لموقع الرحلة التفاعلية

## التشغيل على جهازك

1. فك ضغط ملف `SUBX-Final-Complete.zip`.
2. افتح `index.html` داخل المجلد الناتج عبر Chrome أو Edge أو Firefox.
3. تأكد أن المجلدين `assets` و`css` و`js` موجودان بجانب `index.html`.

يمكنك أيضًا تشغيل `SUBX-Final-OneFile.html` مباشرة دون فك مجلدات؛ كل الصور والتنسيقات والبرمجة مضمّنة بداخله. **لا تحتاج إلى إنترنت** لعرض الموقع.

## طريقة الحركة

- الروبوت ليس مثبتًا في نافذة المشاهدة. صورة الروبوت جزء من الصفحة وتتقدم معها طبيعيًا.
- أثناء النزول تتحرك طبقة الروبوت، ثم تظهر مرحلة التفكيك وتتباعد القطع، ثم مرحلة المعالج، ثم الأكواد المتحركة.
- التغيّرات مربوطة بموقع التمرير الفعلي؛ عند الصعود تعود الحركة.
- الموقع يستخدم صورًا سينمائية واقعية وتأثيرات CSS/JavaScript ذات عمق بصري؛ **ليس نموذجًا هندسيًا ثلاثي الأبعاد قابلًا للدوران الحر**.
- روعيت إعدادات النظام لتقليل الحركة.

## أقسام الموقع

الرئيسية، التفكيك، المعالج، عالم الأكواد مع تبويبات ونسخ، واجهة توضيحية تفاعلية لمشروع أموالي، الخدمات، خطوات العمل، تعريف SUBX، الأسئلة الشائعة، ونموذج إعداد رسالة مشروع قابل للنسخ.

## رفع الموقع على GitHub Pages

1. افتح مستودع GitHub واجعله عامًا إذا رغبت في نشره على صفحات GitHub العامة.
2. **ارفع محتويات المجلد** إلى جذر المستودع، وليس ملف ZIP المضغوط.
3. تأكد أن `index.html` في جذر المستودع وأن `assets/`, `css/`, `js/` بجانبه.
4. من Settings ← Pages اختر Deploy from a branch ثم `main` و`/ (root)`.
5. انتظر نشر GitHub Pages وافتح عنوان النشر من إعدادات Pages.

## تعديل المحتوى

- `index.html` — النصوص والأقسام.
- `css/style.css` — التصميم والتجاوب والمؤثرات.
- `js/main.js` — استجابة التمرير وتفاعلات الأزرار.
- `assets/` — الصور والأيقونة والشعار.

## ملاحظات الوظائف

- تبويبات محرر الكود تعمل وتغيّر النص، وزر النسخ يعمل وفق أذونات المتصفح.
- تبويبات هاتف أموالي تعرض حالات **توضيحية فقط**؛ ليست مرتبطة بقاعدة بيانات أو بيانات مالية حقيقية.
- نموذج التواصل ينسخ وصف المشروع إلى الحافظة؛ لا يرسل أي بيانات إلى خادم، لذلك يجب لصق النص في وسيلة تواصل لاحقًا.
- لا توجد روابط تواصل أو بيانات اتصال مخترعة.
