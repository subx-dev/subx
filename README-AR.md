# SUBX — رحلة الروبوت والمعالج والأكواد

## ما الذي تغيّر؟

المشهد الافتتاحي الآن يعتمد على حركة التمرير من الزائر (Scroll Scrubbing) وليس فيديو، وليس حركة تتكرر وحدها. حركة التمرير إلى أسفل **أو** الرجوع إلى أعلى تتحكم في المرحلة مباشرة، ويمكنك التراجع لإعادة تجميع الروبوت.

- **المرحلة الأولى:** روبوت معدني واضح، يقترب تدريجيًا عند التمرير.
- **الثانية:** تفكك الهوائي والرأس والأذرع وألواح الصدر ثم الأرجل، مع ظهور الهيكل الداخلي.
- **الثالثة:** لوحة إلكترونية ومعالج SUBX يظهران من قلب الروبوت ثم يقترب المعالج إلى أن يملأ المشهد.
- **الرابعة:** انفجار رموز وأكواد برمجية عشوائية التوزيع، ملونة ومتزامنة مع التمرير (لا علاقة لها بأكواد تطبيق أموالي).
- بعد نهاية هذه الرحلة، تنزل بصورة طبيعية إلى بقية الموقع: تعريف SUBX والخدمات ومراحل العمل والمشاريع والتواصل.

## التشغيل

1. فك ضغط ملف ZIP.
2. افتح `index.html` في Chrome أو Edge أو Firefox أو متصفح جوالك.
3. **انزل في الصفحة** لتجربة تفكك الروبوت. العودة إلى أعلى تعيد تركيب أجزائه.
4. الملف `amwali.html` صفحة مستقلة لمشروع أموالي ضمن قسم الأعمال، وليست جزءًا من حركة الروبوت.

**ملاحظة مهمة:** لا يحتاج الروبوت ولا الأنيميشن إلى إنترنت، ولا يعتمد على WebGL أو ملفات نماذج خارجية أو Three.js. النموذج مرسوم بتقنية SVG داخل HTML، وحركته بالـ JavaScript. لذلك يبقى الروبوت ظاهرًا حتى على الأجهزة التي لا تدعم WebGL، لكنه رسوم متجهية بمحاكاة للعمق وليس مجسمًا ثلاثي الأبعاد حقيقيًا.

## GitHub Pages

- ارفع `index.html` و`amwali.html` و`css/` و`js/` و`assets/` مباشرة إلى **جذر المستودع** (لا ترفع ملف ZIP بوصفه الموقع، ولا تضع الملفات داخل مجلد إضافي بالخطأ).
- من Settings → Pages اختر Deploy from branch → main → /(root).
- الموقع لا يحتاج Backend، لكن نموذج التواصل يفتح برنامج البريد، وليس إرسالًا مباشرًا من الخادم.
